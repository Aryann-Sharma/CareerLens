# CareerLens 0.2.0

This is the first published release. Earlier work used version 0.1.0 internally
without a release tag. Compared with that application, CareerLens now supports
guest analysis, local trained extraction and semantic matching, editable skill
review, spelling suggestions, job PDF/photo imports, reusable private résumés,
and saved learning roadmaps. See the [changelog](../../CHANGELOG.md) for details.

The version remains below 1.0 because extraction still needs review and public
hosting features such as password recovery and request throttling are not
implemented. The release is a tested local application, not a public deployment.

## Models included in the application

The application supports the fine-tuned DistilBERT extractor and the pretrained
MiniLM matching model. The newer context and occupation classifiers remain
offline candidates; publishing this release does not promote them.

Source archives do not include model weights, model caches, uploaded files, or
local databases. Follow the [README](../../README.md) to download MiniLM and the
[contextual model guide](../contextual-model.md) to train/export the extractor.
Without installed weights, choose **Find listed technical skills** and **Match
skill names only**. Uploaded résumé PDFs must contain selectable text.

## Upgrade an existing local installation

Back up the database before applying migrations. Stop the old server, activate
the project's Python 3.12 environment, and check out the release tag:

```text
git fetch origin --tags
git switch --detach v0.2.0
python -m pip install -r backend/requirements.txt
python -m alembic upgrade head
python -m alembic check
python -m uvicorn backend.app.main:app
```

Migrations through `0007` add matching/extraction evidence, saved résumés, and
saved roadmaps. Existing analyses are retained. Keep the same database URL and
signing secret. If your local environment explicitly sets `APP_VERSION`, update
it to `0.2.0`; otherwise the application uses the new default. Do not overwrite
your environment file with the example file.

Check `/health/ready`, then verify login, an analysis, saved history, résumé
reuse, and a saved roadmap. Catalog-only analysis remains available when models
are missing. Model installation is separate from database migration.

## Verification

The release checks cover the complete backend and Chromium suite with installed
models, document imports, saved accounts, and all recorded context regression
sets. Additional checks use a disposable PostgreSQL database and newly seeded
skill combinations. Exact results are recorded in the
[testing guide](../testing.md#verification-record).

- Complete local suite: **2,222 passed**; the PostgreSQL-only case was checked
  separately.
- PostgreSQL integration and all browser journeys: **130 passed** across two
  runs, including the 20 cases that require trained weights.
- Additional seeded input checks: **408 requests passed**.
- Dependency, syntax, version, documentation-link, and whitespace checks passed.

Database/browser runs repeat some of the same workflows; their counts should
not be added together as unique tests. No application bug was found in this
release pass. The code changes for release preparation are the version default
and example configuration; model weights and prediction behaviour are unchanged.

Passing software tests does not mean every extracted skill is correct. Model
quality is reported separately in the [extraction guide](../contextual-model.md)
and [context candidate report](../context-curriculum.md).

## Known limits

- The score measures detected-skill coverage, not suitability or proficiency.
- Some indirect wording, sarcasm, typos, and phrase boundaries are still missed.
- Semantic suggestions map to 18 catalog skills; other phrases need exact
  profile matches or manual review.
- Image recognition can lose spaces or headings. Review and edit imported text.
- Scanned/image-only résumé PDFs are unsupported.
- Email verification, password reset, token revocation, and request throttling
  remain future work. Public hosting has not been configured.
- Browser verification uses Chromium; other browser engines are not certified.
